## 📖 About

**Python Mastery Notes** is an open, organized collection of study notes covering the Python programming language in depth — from syntax and data structures to concurrency, typing, packaging, and applied data/AI tooling.

The repository is structured as an **Obsidian vault**, so every folder, note, and link is designed to work seamlessly inside Obsidian with backlinks, graph view, and Maps of Content (MOCs).

Whether you are revising a concept, preparing for an interview, or building a project, these notes are meant to be a **single, coherent reference** — not a scattered pile of snippets.

---

## 🗺️ Curriculum Overview

The vault is organized into **13 modules**, each corresponding to a clear stage in the learning journey.

| # | Module | Focus |
|---|--------|--------|
| 00 | **Meta** | Roadmap, glossary, progress tracker, how to use |
| 01 | **Foundations** | What is Python, setup, `venv`/`uv`, REPL, `__main__` |
| 02 | **Core Syntax** | Variables, numbers, strings, booleans, `None` |
| 03 | **Data Structures** | Lists, tuples, dicts, sets, comprehensions, unpacking |
| 04 | **Control Flow & Functions** | Conditionals, `match`, loops, closures, iterators vs generators |
| 05 | **OOP** | Classes, dunder methods, inheritance & MRO, dataclasses, ABCs/Protocols |
| 06 | **Errors & Context** | Exceptions, custom exceptions, context managers, logging |
| 07 | **Advanced Python** | Decorators, generators deep dive, `itertools`, `functools`, scoping |
| 08 | **Modules & Packaging** | Import mechanics, packages, project layout, `uv` deep dive |
| 09 | **Types & Quality** | Type hints, advanced typing, `mypy`, `ruff`, `pytest` basics |

| 13 | **Shipping** | Advanced `pytest`, build & publish, GitHub Actions, debugging & profiling |

## 🚀 How to Use These Notes

**Option 1 — Read as plain Markdown**
Browse the folders directly on GitHub. Start with [`00 - Meta/Roadmap.md`](./00%20-%20Meta/Roadmap.md).

**Option 2 — Open as an Obsidian Vault (recommended)**
1. Clone the repository:
   ```bash
   git clone https://github.com/hala-kadour/python-mastery-notes.git
   ```
2. Open Obsidian → **Open folder as vault** → select the cloned folder.
3. Begin at `00 - Meta/Roadmap.md` and follow the MOCs.

> 💡 The MOC (`_MOC ...`) file at the top of every module acts as a hub — it links to all notes inside that module and keeps navigation fast.

## ✍️ Note Convention

Every note follows a consistent structure to make revision easier:

- **Definition** — what the concept is, in one paragraph
- **Syntax / Examples** — minimal, runnable code
- **Common Pitfalls** — what usually goes wrong
- **Best Practices** — idiomatic usage
- **Further Reading** — curated links
