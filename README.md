## 🗺️ Inside the Vault (The Knowledge Tree)

This is not just a standard repository; it's an interactive **Knowledge Tree** built with **Obsidian**, synced to **GitHub**, and published as a digital garden using **Quartz**.

The curriculum is structured into 13 core modules to guide you from the basics to advanced applications:

| Module | Description |
| :--- | :--- |
| **00 - Meta** | The roadmap, reader's guide, glossary, and progress tracker. |
| **01 - Foundations** | Setup, virtual environments (`venv`), and the REPL. |
| **02 - Core Syntax** | Variables, numbers, strings, booleans, and the magic of `None`. |
| **03 - Data Structures** | Lists, tuples, dictionaries, sets, and comprehensions. |
| **04 - Control Flow** | Conditionals, loops, function parameters, and closures. |
| **05 - OOP** | Classes, Dunder methods, inheritance, and dataclasses. |
| **06 - Errors & Context** | Exception handling, custom errors, and context managers. |
| **07 - Advanced Python** | Decorators, generators, `itertools`, and `functools`. |
| **08 - Modules & Packaging** | Import mechanics, project layouts, and `uv` deep dive. |
| **09 - Types & Quality** | Type hints, `mypy`, `ruff`, and testing with `pytest`. |
| **10 - Concurrency** | The GIL, threading, multiprocessing, and `asyncio`. |
| **11 - Files & Data** | File I/O, `pathlib`, JSON/CSV, and `datetime`. |
| **12 - Applied AI Data** | Practical data science with `numpy` and `pandas`. |
| **13 - Shipping** | Advanced testing, CI/CD with GitHub Actions, and debugging. |
| **99 - Practice** | Exercises and solutions to test your spells. |

## 🚀 How to Use These Notes

1. **Browse the Digital Garden**: Explore the interconnected notes via the Quartz-powered website. *(Link coming soon!)*
2. **Open the Vault**: Clone this repository and open the folder using [Obsidian](https://obsidian.md/) to see the graph view and edit notes locally.
3. **Track Your Progress**: Start by opening `Progress Tracker.md` inside the `00 - Meta` folder. Check off lessons as you go.
4. **Create New Notes**: Use the templates in the `Templates/` folder to maintain a consistent structure.
