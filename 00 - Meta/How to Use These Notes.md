# 📖 How to Use These Notes

> A short guide for anyone who lands on this repository for the first time. Read this before opening any lesson.

## 👋 Welcome

This is an **open, structured Python learning vault**. It's written as **Obsidian notes** and published as a GitHub repository.

- **Explanations** are in English.
- **Code** is in English (of course).
- **Structure** follows the roadmaps in [[Roadmap]].

## 🎯 Who this is for

- Absolute beginners — no prior programming required.
- Self-taught developers filling gaps.
- AI/ML learners who need a solid Python foundation before touching PyTorch.

## 🧭 How to navigate

### The three key files

| File | Purpose |
|------|---------|
| [[Roadmap]] | The master plan — 13 modules |
| [[_MOC Foundations]] (and other `_MOC *.md`) | Index for each module |
| [[Progress Tracker]] | Your personal checklist |

### The MOC pattern

Every module has a `_MOC <Module>.md` file (Map of Content). It lists lessons, concepts, self-checks, and gotchas. **Start there** before reading individual lessons.


### The lesson structure

Every lesson follows the same template:

```
🎯 Learning Goals      → what you'll be able to do
📖 Full Explanation     → the deep dive
💻 Code                 → runnable examples
⚠️ Gotchas & Traps      → common mistakes
🧪 Practice             → exercises
🔗 Related             → connections to other lessons
```


## 🛠️ Prerequisites

Before starting **Module 0**, you need:

- A Windows, macOS, or Linux machine (the repo primarily uses Windows commands, but concepts are cross-platform)
- About 60–120 minutes of focused time per lesson
- A willingness to **type and run** the examples (not just read them)

You do **not** need any programming experience.

## 📋 Recommended workflow per lesson

1. **Read** the lesson from top to bottom — don't skip the "Gotchas & Traps" section
2. **Type** the code examples into your own environment (don't copy-paste!)
3. **Run** the code and observe the output
4. **Modify** the code — break it, fix it, extend it
5. **Do the practice exercises** — even if they seem simple
6. **Move on** only when all boxes are checked

## 🧠 Learning philosophy

This vault is built on three principles:

1. **Depth over speed.** Every lesson teaches *what*, *why*, *how*, and *gotchas*. We don't do "hello world in 5 minutes."
2. **Mental models over memorization.** You'll learn *why* `x = 5` creates a reference, *why* `int` is arbitrary precision, *why* the GIL exists. This means you'll be able to reason about code you've never seen.
3. **Practice over theory.** Every lesson has runnable code and exercises. You'll type every line yourself.
